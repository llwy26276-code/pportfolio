CASE 01

游戏买量视频｜结构化创意拆解

从用户第一秒注意力出发，将一条买量视频拆成 A / B / C 三段，让「为什么看下去、为什么想玩、下一步做什么」形成完整闭环。

视频结构拆解

A钩子 Hook
第一时间让用户停下来

填写：钩子是什么？制造了什么冲突 / 好奇 / 反差？为什么用户愿意继续看？

创意说明 在这里补充钩子的设计逻辑、用户心理、台词 / 字幕策略等。

B卖点 Value
把「想看」转化为「想玩」

卖点可以自由拆成多个模块。每个模块都可以放多张图片，后续可继续增加。

卖点 01可修改标题

填写该卖点的表达方式、视觉重点与用户利益点。

卖点 02可修改标题

填写该卖点的表达方式、视觉重点与用户利益点。

C结尾引导 CTA
完成信息收束，引导下一步行动

填写结尾如何承接前面的卖点，以及最终采用了什么引导方式。

引导逻辑 在这里说明 CTA 为什么这样设计，以及它和前面卖点之间的关系。

01

钩子逻辑

填写：第一秒抓什么、冲突是什么、用户为什么停留。

02

卖点逻辑

填写：卖点排序、视觉呈现、利益点与节奏关系。

03

效果逻辑

填写：动效如何服务信息强调，而不是单纯炫技。

04

节奏逻辑

填写：哪里快、哪里停、哪里给信息，如何形成观看节奏。

04 / ABOUT

关于我

我想做的，不只是把视频做出来， 而是参与决定“应该做什么”。

我是一名正在向视频创意策划发展的内容创作者， 具备游戏买量、品牌视频、AIGC内容和校园微电影实践经验。

我的关注点从单纯的制作执行逐渐转向： 创意为什么成立、镜头为什么这样安排、用户为什么愿意继续看， 以及素材如何通过反馈不断迭代。

我希望在实际项目中继续强化创意策划、用户洞察、 脚本分镜和内容策略能力，同时保留从想法到成片的执行能力。
